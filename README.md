# osysharp/site

Osy# packages, one per folder. Each folder is a package of its own, with its own README, tests and releases (tagged `<folder>/v<version>`).

| Folder | Package | What it is |
|---|---|---|
| [`looks/`](looks/) | `Osysharp.Site.Looks` | the general site contract for looks — hero, picture with words, quote, opening hours, address, sign-up, gallery, announcement, footer — as block TYPES each look draws in its own design. |

- [`llms-full.txt`](https://osysharp.com/llms-full.txt) — the whole reference and specification as one Markdown file, for a coding agent
